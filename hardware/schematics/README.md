# faun hardware documentation

The [development guide](../../docs/DEVELOPMENT.md) documents the base module header and MOD interface. [User manual](../../docs/USER_MANUAL.md) · [Manuale italiano](../../docs/MANUALE_IT.md).

Current base circuit schematics and native CAD are not yet included. Historical MOD diagrams are available in the MOD1-MOD6 directories. New hardware contributions should include editable CAD, a readable schematic PDF, connector orientation, a matching BOM and PCB files.
