# OVERVIEW
faun is made of 6 jacks. On the back you will find 15 pin headers with the following structure:

<img width="500" height="500" alt="faun pins overview" src="https://github.com/user-attachments/assets/3f36f672-6e49-4e1b-a14f-2d3eb4d2edd6" />

As you can see both A and B stereo jacks have independent Left and Right channels.
All GNDs are connected to a single pin (X5). This means that for standalone they are connected together, but for MODs GND can simply be used with a single Pin.
For each mono jack, the signal pin are doubled for standalone uses (check the relative chapter).
  - For example: Jack "1" has pins Y1 and Z1 associated!

Pins Y5 and Z5 are the normalised pin of the switch in the mono jacks 2 and 4.

I spent some time trying to ordering the pins in the most comfortable and usable way, in order to achieve different standalone faun (read as: without any MODs) uses simply by using jumper connectors!
